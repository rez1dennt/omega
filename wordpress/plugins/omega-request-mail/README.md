# Омега — заявки на почту

Отдельный плагин подключает обе формы темы к собственному REST-обработчику. Отправитель и получатель фиксированы на omegakomplekt@mail.ru; e-mail посетителя используется только в Reply-To. Проверяются HTTPS и Origin, согласие, поля, UUID заявки, ловушка ботов и частота запросов. Повтор с тем же UUID не отправляет письмо повторно. Технические записи без текста обращения удаляются запланированным заданием через час.

Настройка: вне публичного каталога сайта создайте файл omega-mail-private/config.php с правами 0600 и содержимым:

```php
<?php
return ['enabled' => true, 'password' => 'ПАРОЛЬ_ПРИЛОЖЕНИЯ_MAIL_RU'];
```

По умолчанию каталог размещается на два уровня выше корня WordPress; при другой структуре можно задать абсолютный путь константой OMEGA_REQUEST_CONFIG в wp-config.php. Каталог должен быть доступен PHP и недоступен по HTTP. Пароль не должен попасть в репозиторий, HTML, JavaScript или журналы.

После проверки запрошенного пользователем теста о фактическом получении письма нужно убедиться в почтовом ящике. Данные SMTP не сохраняются в административных полях и не отправляются посетителям.
