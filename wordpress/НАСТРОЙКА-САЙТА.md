# Как редактировать сайт

1. Войдите в WordPress и откройте слева **Настройка сайта**.
2. Выберите нужную вкладку. Текущие тексты, фотографии, таблицы и иконки уже заполнены.
3. Измените значение и нажмите **Сохранить раздел** справа. Затем обновите страницу сайта.

Сохраняйте изменения перед переходом в другую вкладку. Поиск находит поля в открытом разделе и раскрывает нужную группу.

| Что нужно изменить | Где находится |
| --- | --- |
| Телефоны, почта, адрес, график, реквизиты, название и описание сайта для поиска | Компания и реквизиты |
| Логотип для тёмного/светлого фона, значок вкладки браузера | Логотип и значок сайта |
| Меню и подписи шапки | Шапка и меню |
| Заголовки, тексты, фото, карточки | Вкладка соответствующей секции |
| Куда ведёт кнопка | Кнопки и ссылки |
| Значок рядом с кнопкой или текстом | Иконки: выберите готовый или своё изображение |
| Контурные линии, фигурные края | Фоновая графика |
| Поля заявки и подписи кнопок | Форма заявки / Форма подбора полотна |
| Сообщения проверки и отправки формы | Сообщения и доступность |
| Карта и её описание | Контакты и карта; кнопки маршрута — Кнопки и ссылки |
| Тексты документов | Политика персональных данных / Согласие на обработку данных |
| Рекомендации, размеры, значения TPI | Данные подбора шага / две вкладки таблиц |

Для замены фото нажмите карандаш над изображением или «Добавить изображение», откройте библиотеку файлов и выберите фото. Можно загрузить новый файл с компьютера. Поле описания под фотографией помогает поиску и доступности. Для нового логотипа удобен PNG/WebP с прозрачным фоном.

В таблицах меняйте обычные ячейки. Диаметры и толщины должны идти по возрастанию; пустая клетка означает отсутствие рекомендации. Подсказка укажет ошибку до сохранения. Меняйте технические рекомендации только по проверенным данным.

В документах доступны обычные абзацы, списки и ссылки. Общие реквизиты подставляются из вкладки компании. Кнопка скачивания реквизитов может формировать файл из текущих полей или выдавать выбранный вами файл.

Кнопка первичного заполнения нужна при первой установке: она добавляет только отсутствующие поля и не сбрасывает ваши правки. На локальном сайте заполнение уже выполнено. При переносе на другой WordPress вместе с темой и плагином перенесите базу данных и папку uploads, чтобы сохранить свои тексты и фотографии.
