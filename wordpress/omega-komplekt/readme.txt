== Установка ==

1. Внешний вид → Темы → Добавить тему → загрузите omega-komplekt-wordpress-theme.zip.
2. Активируйте тему. Главная работает сразу, без сборки npm и конструктора.
3. Для полного редактирования активируйте отдельно ACF PRO и собственный плагин «Омега — Настройка сайта».
4. Настройка сайта → Первичное заполнение текущим контентом → Заполнить текущим контентом.
5. Для изменения выберите вкладку, измените поля и нажмите «Сохранить раздел».

На подготовленном Local-сайте omega заполнение уже выполнено.

== Редактирование ==

26 разделов: общие реквизиты и контакты, логотипы, шапка, все секции главной, изображения, иконки, ссылки, формы и сообщения, Cookie, документы, карта и таблицы TPI. Документы редактируются визуально, таблицы — обычными ячейками. Все поля заполнены текущими значениями; изображения импортируются в медиатеку. Сохранённые пустые значения не заменяются исходным текстом.

== Формы ==

Серверный обработчик и SMTP подключаются отдельно. По умолчанию endpoint пустой, сеть для отправки не вызывается. В теме и плагине контента нет почтового пароля, SMTP-кода или PHPMailer. При проверках заявки и письма не отправляются.

== Перенос ==

ZIP содержит тему и исходный контент. Для переноса пользовательских правок переносите также базу данных и wp-content/uploads. ACF PRO устанавливается отдельно, коммерческие файлы и лицензия в комплект не входят. Подробности и контракты — в README.md.
