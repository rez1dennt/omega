Классическая самостоятельная тема с текущим дизайном ООО «Омега Комплект».

== Установка ==

1. WordPress → Внешний вид → Темы → Добавить новую → Загрузить тему.
2. Выберите omega-komplekt-wordpress-theme.zip и нажмите «Установить», затем «Активировать».
3. Откройте главную. Дизайн работает без ACF, конструктора, импорта и сборки npm.
4. Проверьте реквизиты и индексацию в Настройки → Чтение. Тема сохраняет выбранную настройку WordPress.

При установке по FTP загрузите каталог omega-komplekt в wp-content/themes/.
Не загружайте ZIP всего репозитория или архив PHP-хостинга как тему.

== Что работает ==

Главная и девять её секций; локальные фото и шрифт Golos Text; интерактивные преимущества;
таблица TPI; карточки оборудования; шапка и мобильное меню; формы и маска телефона;
модалки с блокировкой прокрутки; контакты и Яндекс Карта; Cookie-настройки; политика и согласие.
Предусмотрены обычные страницы, записи, архив, поиск и страница 404.

== Контент и формы — следующий этап ==

Сейчас главная выводит согласованные данные из data/*.php, а не поля ACF или редактор Gutenberg.
Будущий плагин подключается через фильтры omega_theme_content и omega_theme_request_settings.
Документация для разработчика находится в README.md и content-map.json внутри темы.

По умолчанию обработчик заявок не подключён: пустой endpoint не вызывает сетевых запросов.
Форма сохраняет валидацию, введённые данные и не показывает неподтверждённую отправку.
SMTP, пароли, почтовый обработчик и PHPMailer в тему не включены.
Плагин заявок и SMTP подключаются отдельным следующим этапом. Отправка писем при подготовке темы не проверялась.

== Документы ==

Сразу доступны ссылки ?omega_document=privacy и ?omega_document=consent.
Если опубликованы страницы со slug privacy и consent, используются их обычные URL.
Страницы можно оставить пустыми для встроенного текста либо наполнить собственным содержимым.
Активация темы не создаёт и не изменяет страницы, записи и настройки сайта.
