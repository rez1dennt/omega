# Общая сетка станков и компактная плашка IDEAL

По уточнению клиента четыре станка объединены в одну сетку 2×2: с гидроразгрузкой, полуавтоматический, автоматический и магнитный сверлильный LENZ Steyr-35. Отдельный заголовок и широкий горизонтальный блок магнитного станка удалены. Все четыре карточки используют одинаковую вертикальную структуру, размер фоторамки, отступы и выравнивание действий. На экранах уже 768 px — одна колонка. Рольганги остаются отдельной существующей карточкой.

Общий заголовок группы — «Станки для производства», подпись — «Резка и сверление металла». В четвёртой карточке модель указана в строке характеристик; кнопка передаёт полное название выбранного станка в заявку.

Плашка на фото IDEAL ограничена шириной 23rem и доступной шириной изображения, иконка уменьшена до 24px. Фото сохранено целиком, текст читается и не выходит за рамку. Белый фон фотографий мягко совмещается с общим фоном фоторамки.

Изменения внесены в статическую версию и WordPress-тему. Тема **1.1.1**, устанавливаемый архив `../omega-komplekt-wordpress-theme.zip`: 104 файла, 1 986 273 байта. SHA-256: `4189131f16908a3be046fc3accd0996ad9dc8142ee97c606c6c72812e48e2664`.

Проверки: `verify:equipment-layout` — семь ширин от 320 до 1440px, реальная сетка 2×2, одинаковые рамки, выравнивание кнопок, компактная плашка и контекст заявки. Исходная регрессия зафиксировала три карточки вместо четырёх в общем контейнере. Дополнительно `verify:equipment`, `verify:pages`, `verify:client` и проверка точного ZIP под WordPress через `verify:wordpress`. QA-скриншоты и результаты находятся в исключённом из Git `qa/`. Реальные заявки, API POST и письма не отправляются.
