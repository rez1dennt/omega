# Непрерывный подбор труб — план реализации

**Цель:** подбор для Ø89, Ø108, Ø90 со стенкой 3/5 мм и промежуточных размеров без требования совпадения с табличной ячейкой.

**Архитектура:** один режим рекомендаций LENOX для биметаллических полотен по опубликованной непрерывной диаграмме «Tubing/pipe/structurals», официальный каталог 2026, стр. 10. Наружный диаметр проверяет физическую корректность трубы и переносится в заявку; методика LENOX выбирает шаг по стенке. Оригинальные таблицы заказчика и BAHCO сохранены как отдельные справочники, их данные не перемешиваются с новым алгоритмом.
