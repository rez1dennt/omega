# Полное редактирование сайта через ACF Pro

**Цель:** заполненная настройка всего содержимого WordPress, понятная человеку без знания кода, в меню «Настройка сайта».

**Архитектура:** отдельный плагин `wordpress/plugins/omega-site-settings`; тема сохраняет безопасные исходные значения и получает данные через `omega_site_settings`/`omega_theme_content`. ACF хранит структурированные поля, публичный снимок исключает сотни запросов на фронтенде. Репозиторная и указанная локальная тема синхронизируются после резервной копии.

## Задачи

- [x] Полная инвентаризация: секции, шапка/подвал, изображения/alt, иконки/декор, ссылки/действия, формы/runtime, cookie, документы, таблицы и служебные страницы.
- [x] Схема с русскими названиями и отдельным сохранением вкладок: компания, брендинг, секции главной, иконки/декор, формы/сообщения, таблицы, документы/cookie, системные страницы. Не показывать клиенту JSON, PHP, SVG-path или технические ID.
- [x] Безопасное ядро: ACF options pages, schema builder, snapshot, capability/nonce, идемпотентное заполнение только отсутствующих данных, импорт изображений/файлов в медиатеку.
- [x] Тема: typed helpers для строк, изображений, иконок и кнопок; все текущие значения доступны через поля; привязать фон/preload к выбранной фотографии.
- [x] Runtime: все сообщения/подписи из `window.OmegaTheme.ui`; исходная подпись submit сохраняется, выбор шага не зависит от редактируемого текста.
- [x] Единый provider таблиц PHP/JS/TPI dropdown; редактирование матриц обычными ячейками с проверкой данных.
- [x] Документы: единый ACF-приоритет для native/query URL, визуальные редакторы всех разделов, общие реквизиты; транспорт SMTP не включать.
- [x] Синхронизировать Local Sites, активировать отдельный плагин и заполнить настройки через защищённый процесс админки.
- [x] Проверить реальное сохранение текста, фото, иконки, кнопки, сообщения, документа и таблицы; права/nonce, повторное заполнение, намеренно пустые поля, адаптивность, формы без отправки.
- [x] Собрать тему и собственный плагин в отдельные ZIP без коммерческого ACF, подготовить памятку клиенту и push исходников.

## Контракты

- `omega_theme_settings(string $section, array $defaults = []): array` — raw ID медиа, массивы и сохранённые пустые значения.
- `omega_theme_setting(string $section, string $key, mixed $fallback)` — одно поле.
- `omega_theme_content` — совместимый адаптер прежних плоских секций; media ID превращается в URL только здесь.
- `config/*.php` возвращает `section => ['title', 'fields' => key => descriptor]`; descriptor содержит `type`, `label`, `default`, вложенные `fields` и параметры ACF.
- Корневое имя/ключ ACF: `omega_<section>` / `field_omega_<section>`, `post_id=omega_site`.
- В runtime передаются `ui.{request,site,navigation,pitch}`, `pitchData` и транспортная версия согласия. Секреты/SMTP отсутствуют в публичных настройках.

## Границы

ID, селекторы, имена payload, алгоритм, ограничения безопасности и физическая проверка размеров остаются кодом. Все редакционные строки, значения таблиц, источники и видимые медиа редактируются. Исходные файлы коммерческого ACF и лицензия не копируются в репозиторий/архивы.

## Проверка реализации

- Реальный Local: WordPress 7.1.3, PHP 8.2.29, ACF PRO 6.7.0.2; собственный плагин активирован.
- 26 options-разделов открываются отдельными вкладками, данные и исходные медиа заполнены через защищённую кнопку админки. Повторный проход добавляет только отсутствующие поля.
- Нативные сохранения: текст, намеренно пустая строка, фото из медиатеки/alt/фон, иконка, действие кнопки, сообщение проверки формы, телефон/tel, визуальный документ и таблица. Изменения проверки возвращаются к исходному содержимому.
- Визуальный редактор документов выводит абзацы через wpautop. Постоянные якоря хранятся вместе со строками и скрыты от редактора; новые и дублированные строки получают собственный ID до native ACF type handler.
- Исправлены обнаруженные регрессии: недоступные скрытые options pages, повторная подстановка реквизитов, skip-link с внутренних страниц и устаревшие неиспользуемые поля мобильных фото.
- Проверки работают без отправки заявок/почты. Коммерческие файлы и лицензия ACF, БД и uploads не входят в исходники или ZIP.
