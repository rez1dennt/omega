# Подключение заявок WordPress

- Создать отдельный серверный обработчик REST, не меняя тему и плагин ACF.
- Проверять HTTPS, источник запроса, согласие, данные, повторные отправки и ограничение частоты.
- Подключать SMTP Mail.ru через WordPress PHPMailer; пароль хранить в отдельном файле вне публичной папки.
- Проверить серверную валидацию и обработку ошибок с имитацией почты до установки.
- Установить на указанный хостинг, проверить настройки без раскрытия секретов и отправить одну явно помеченную тестовую заявку.
