# Визуальная основа «Омега Комплект»

**Последняя правка 14 октября 2026:** текущий дизайн повторяет новый прикрепленный референс; светлая самостоятельная итерация отменена. См. match-reference-2026-10-14.md. Описание ниже относится к первой версии.

Источник композиции — приложенный макет. Прямое указание заказчика заменяет его красный палитрой № 4: #1A1A1D, #4E4E50, #6F2232, #950740, #C3073F. Белый и светло-серый — нейтральные поверхности из макета.

Девять секций: шапка, первый экран, преимущества, производство, заказ и консультация, марки станков, доставка, контакты и карта, футер. Плотная композиция, косые тёмные плоскости, тонкие красные линии, узкие жирные заголовки. Desktop пропорции рассчитываются по референсу 941 × 1672. На мобильных сетки складываются, диагональная геометрия сохраняется.

Сайт — демонстрация оформления. Контакты, реквизиты, сроки и доставка взяты как временный текст из референса; не подтверждены для запуска. Форма показывает сообщение о демонстрационном режиме и не отправляет данные. Изображения подготовлены ImageGen, не являются фотографиями реального производства клиента. Карта иллюстративная; маршрут открывает поиск адреса.

Архитектура: статический HTML, стили с централизованными переменными и отдельный JS для навигации, марки станка и демонстрационной формы. Локальные шрифты и фото. Нет CMS, CRM, backend или тяжёлых библиотек. Разделы HTML можно переносить независимо.

Проверка: браузер 1440, 1024, 768, 390, 360 и 320 px; отсутствие горизонтального скролла, загрузка ресурсов, меню с клавиатурой, Escape, выбор станка, сообщение формы без отправки. Полный desktop-скриншот для сравнения с референсом.
