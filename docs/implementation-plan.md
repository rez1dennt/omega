# План реализации «Омега Комплект»

Цель: адаптивная редактируемая демонстрация всех секций приложенного макета в палитре № 4.

Архитектура: dist/index.html — семантическая страница; dist/styles/tokens.css — палитра; dist/styles/site.css — компоненты и адаптив; dist/scripts/site.js — интерактив; dist/assets — локальные изображения и шрифты; scripts/serve.mjs — локальный сервер; scripts/verify.mjs — браузерная проверка.

- [ ] Подготовить локальные фото, кириллические шрифты, палитру и памятку для печати.
- [ ] Собрать все секции макета, общие иконки SVG, диагональные слои и адаптивные сетки.
- [ ] Добавить доступное мобильное меню, заполнение марки станка и демонстрационную форму без сетевых запросов.
- [ ] Запустить локальный сервер, проверить все размеры и взаимодействия, сохранить скриншоты.
- [ ] Исправить наблюдаемые отличия и выполнить финальную проверку. Передать исходники, предпросмотр и точные цвета.

Проверка: node scripts/verify.mjs. Ожидается отсутствие переполнения на шести размерах, ошибок console, незагруженных картинок/шрифтов; сохранение desktop/mobile снимков; подтверждение состояний меню и формы. Финальный контент и backend вне текущего объёма.
