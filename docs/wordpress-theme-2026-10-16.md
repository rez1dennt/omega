# Тема WordPress: установка и проверка

Архив для установки: `../omega-komplekt-wordpress-theme.zip`  1 839 619 байт. Единственный корневой каталог — `omega-komplekt/`, 98 файлов. SHA-256: `1adb95b904a7462980c43bdf3d79f250e8347dca50ae62a42a638946c05a8395`.

## Установка

WordPress → Внешний вид → Темы → Добавить новую → Загрузить тему → выбрать этот ZIP → Установить → Активировать. Нужны WordPress 6.6+ и PHP 8.1+. Главная работает без импорта, конструктора и ACF; стандартные установки в корне домена и вложенном каталоге используют URL WordPress.

Исходники и подробная карта интеграции: [README темы](../wordpress/omega-komplekt/README.md). Текущий дизайн и компания сохранены. Девять секций, общие элементы, формы, документы, данные и ресурсы разделены. Native page/post/archive/search/404 templates, хуки WordPress, enqueue API, ES import map, дочерняя тема и admin bar предусмотрены.

Контент главной сейчас находится в `data/`; его редактирование через плагин — следующий этап. Техническая таблица TPI сохранена отдельно от редакторского контента. Плагин заявок подключит endpoint через документированный интерфейс. По умолчанию отправка отключена, почтовые пароли и серверный mail-handler в архив темы не входят.

## Проверка точного устанавливаемого ZIP

В настоящем локальном WordPress **7.1.3**, PHP **8.5.6**, официальный SQLite Database Integration **3.1.0** только для QA:

- Распаковка ZIP через PHP ZipArchive, штатные `switch_theme` / `validate_current_theme`, миниатюра JPEG 1200×900.
- 36 проверок маршрутов и размеров: главная, политика, согласие, обычная страница, 404, запись, архив, поиск; desktop 1280, intermediate 768, mobile 360 и 320 px.
- Дополнительно: native и plain permalinks документов, query-документы поверх обычной/статической главной страницы, один правильный canonical, ошибочный/массивный query selector → 404.
- Мобильное меню, переход меню → модалка, перенос категории оборудования, Cookie, маска, только локальная проверка невалидных полей, таблица TPI.
- Формы без JavaScript изначально не отправляются; native GET с контактами не допускается. Endpoint по умолчанию пустой.
- Реальная панель администратора на четырёх ширинах; дочерняя тема с отдельной заменой data module и fallback родительских ресурсов.
- Активация и новый bootstrap не создают и не меняют записи/страницы или посторонние настройки; штатные настройки переключения темы WordPress учитываются отдельно.
- 50 PHP и 10 JS файлов темы прошли syntax checks. Ошибок JS/ресурсов и попыток API/POST — **0**. Отправок писем — **0**.
- Независимая проверка целостности ZIP, структуры каталога, исключений и размера менее 2 MiB. PHP/JS проверены на отсутствие SMTP implementation/password fields.

Команды: `prepare:wordpress`, `dev:wordpress`, `verify:wordpress`, `build:wordpress`. Для проверки ZIP установить `OMEGA_WP_THEME_ZIP` в абсолютный путь к архиву. QA-база, ядро, локальная учётная запись, SQLite drop-in и отчёты находятся в исключённой из Git папке `qa/wordpress/`; в установочный архив они не входят. Почта и исходящие HTTP тестового ядра заблокированы.

Отчёт последнего запуска: `qa/wordpress/verification.json`; тип источника `zip` и SHA-256 совпадают с указанным архивом. Существующие `dist/` и самостоятельный PHP-хостинг не изменялись.
