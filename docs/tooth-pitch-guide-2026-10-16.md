# Таблица подбора шага зуба

Новый блок перед формой `#order`: вкладки «Пруток» и «Труба», быстрый поиск по размерам, полная таблица в раскрывающемся блоке и перенос выбранного шага в существующую форму. Фирменные цвета №4, Golos Text и существующие кнопки сохраняются. На телефоне поиск располагается в одну колонку; широкая таблица труб прокручивается внутри собственного контейнера с закреплённой первой колонкой.

Источник — присланное фото `таблица.jpg`. Переносится 11 диапазонов прутка и матрица 12×10 для труб. Пересекающиеся интервалы возвращают все совпадения. Пустая клетка означает отсутствие значения; округления, интерполяция и выбор ближайшего размера не применяются. Для труб, лежащих рядом, используется строка удвоенной толщины стенки — как в примечании источника. Памятка об обкатке переносится отдельным раскрывающимся текстом.

План: сначала проверить границы и всю матрицу тестами; затем сформировать семантические HTML-таблицы из единого файла данных, добавить локальный поиск и связь с формой; проверить мобильную геометрию, клавиатуру, пустые/ошибочные значения и работу без JavaScript; выполнить регрессионные проверки, обновить Sites, GitHub и архивы.

Без JavaScript доступны обе полные таблицы и памятка. Поиск и выбор не отправляют данные в сеть. Заявки, API POST и SMTP при проверках запрещены. При переносе шага сохраняются введённые посетителем контакты и комментарий; заменяется только предыдущая строка подбора.

## Подтверждённые проверки

Независимая сверка с фото: 11 диапазонов, 106 заполненных клеток трубы и 14 пустых. Неоднозначных цифр не обнаружено. Значения 5/6, 1,1/1,6 и 0,75/1,25 сохранены буквально. Границы диапазонов включены; «свыше 500» применяется строго после 500. Между строками и колонками труб значения не вычисляются.

`verify:pitch-data`: все ячейки, границы, пересечения и правило стенки ×2. `verify:pitch`: восемь ширин 320–1440, вкладки с клавиатуры, корректный/пустой/ошибочный ввод, поиск по Enter, сброс устаревшего результата, перенос и замена предыдущей строки без потери контактов, липкая колонка и no-JS.

Отдельный регресс переполненного комментария сначала воспроизвёл частичный перенос TPI без размеров. Теперь перенос атомарен: если строка не помещается, остаются прежние TPI и комментарий, выводится видимое объяснение. Сам поиск не является отправкой заявки.

Изменение вида вкладок и стрелок использует существующие токены motion; reduced motion выключает переходы. Новая секция не добавляет фотографии, внешние запросы, cookie или JavaScript-библиотеки.
