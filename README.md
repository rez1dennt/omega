# Омега Комплект — демонстрация дизайна

Статическая адаптивная страница по приложенному макету. Палитра № 4 зафиксирована в ПАЛИТРА.md и dist/styles/tokens.css.

Запуск: `npm run dev`, открыть http://127.0.0.1:4173. Установка зависимостей для сайта не нужна. dist/index.html также можно открыть непосредственно в браузере.

Файлы: dist/index.html — разделы и временные тексты; dist/styles/tokens.css — общая палитра; dist/styles/site.css — компоненты и адаптив; dist/scripts/site.js — меню и демонстрационное поведение; dist/assets — локальные шрифты, фото, схема карты, пример реквизитов.

Секции можно переставлять целиком внутри main. Изменение контактных данных выполняется в index.html и assets/rekvizity-demo.txt. Названия марок станков находятся в элементах data-machine.

Форма не отправляет данные и не сохраняет их. Фотографии созданы ImageGen и не изображают реальное производство клиента. Карта — иллюстративная схема. Контакты, реквизиты, доставка и сроки из макета являются временным контентом. Демонстрация закрыта от индексации.

До публичного запуска требуются утвержденная структура, тексты, контакты, реквизиты, настоящая карта и адрес, подтвержденные условия доставки/изготовления, фотографии предприятия, обработчик формы и согласованные юридические документы.

Проверка: `npm run verify` при запущенном сервере. Для инструмента проверки нужен Playwright в локальных node_modules или путь к нему в переменной CODEX_NODE_MODULES. Сам сайт работает без Playwright.
