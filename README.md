# Омега Комплект

Адаптивный сайт ООО «Омега Комплект» с подбором ленточных полотен, разделом станков и рольгангов, модальной заявкой, маской телефона, контактами, доставкой, политикой обработки данных, отдельным согласием и настройками cookie. Палитра № 4 зафиксирована в ПАЛИТРА.md.

Шрифт — **Golos Text**, локальный файл с кириллицей и лицензией SIL OFL 1.1. [Шкала крупной типографики](docs/typography-2026-10-15.md) общая для сайта, форм и документов.

## Почтовая форма

Подготовлена для PHP-хостинга в РФ и SMTP Mail.ru: **omegakomplekt@mail.ru**, smtp.mail.ru:465, TLS. Адрес посетителя — Reply-To. Пароль не находится в браузере или репозитории. Отправка пока выключена, реальные заявки и SMTP-доставка не проверялись и письма не отправлялись.

Для подключения позже нужны пароль внешнего приложения Mail.ru и домен хостинга. [Инструкция подключения](docs/CONNECT-SMTP.md) описывает структуру папок, настройки и требования. Успех в интерфейсе показывается только после подтверждения серверного обработчика; ошибка сохраняет введённые данные.

Встроенная форма отправляет заявку напрямую через тот же PHP-обработчик: параметры, контакты и отдельное согласие находятся в самой форме. Остальные кнопки заявки открывают модальную форму. Обе формы используют общую валидацию, маску и защиту от повторной отправки; открытие модалки не отправляет данные.

Секция формы компактная; необязательные имя и компания раскрываются по клику. Ошибки поясняют, что исправить, выделяют поле и собираются в список с переходами. [Подробности и замеры](docs/compact-validation-2026-10-15.md). `npm run verify:validation` проверяет только локальную валидацию без отправки формы и обращений к API.

[Раздел оборудования](docs/equipment-2026-10-15.md) сравнивает станки с гидроразгрузкой, полуавтоматические и автоматические; рольганги представлены отдельно. Для каждой категории использовано каталожное фото PILOUS, локальные WebP оформлены в монохромной гамме сайта. [Источники изображений](docs/assets.md). Кнопки открывают заявку с выбранной категорией. Черновики параметров полотен и каждой категории оборудования сохраняются раздельно. Проверка `npm run verify:equipment` не отправляет заявки.

## Структура

- `dist/` — HTML, CSS, JavaScript, локальные фото и шрифты; статический просмотр сайта.
- `php/public_html/api/request.php` — публичный PHP endpoint.
- `php/private/` — обработчик, настройки-пример и PHPMailer 7.1.1; размещается вне публичного корня.
- `scripts/` — локальный просмотр, генерация юридических страниц, сборка и проверки.
- `docs/` — инструкции и история решений. Актуальная отправка: mail-preparation-2026-10-14.md.

Собрать для хостинга: `npm run build:hosting`. В `release/hosting` появятся `public_html`, соседняя `private` и инструкция. Загрузка `dist` на GitHub Pages или статический хостинг не запускает PHP. Пакет содержит библиотеку почты, Composer не требуется. PHP 8.1+, OpenSSL, session и HTTPS обязательны.

Копия `php/private/mail.example.php` → `private/mail.local.php` на сервере. Указать пароль приложения, точный HTTPS-origin и включить `enabled`. Настоящая конфигурация, сессии и сборки исключены из Git и архивов исходников. Никаких проверочных POST/писем без отдельного разрешения заказчика.

## Локальный просмотр

`npm run dev`, затем http://127.0.0.1:4173. Установка зависимостей для самого сайта не нужна. Этот сервер показывает интерфейс и не исполняет PHP.

## Проверки

`npm run verify`, `verify:typography`, `verify:modal`, `verify:polish`, `verify:dropdown`, `verify:mail`. Browser-проверкам нужен Playwright в node_modules или путь CODEX_NODE_MODULES. По указанию заказчика проверки не нажимают окончательную отправку и не тестируют доставку. PHP проверяется `php -l`. QA-скриншоты и отчёты не попадают в Git.

## Документы и данные

Политика — `/privacy/`, согласие — `/consent/`; источник и общий шаблон в `scripts/render-legal.mjs`, генерация `npm run render:legal`. Cookie-настройки хранят только локальный выбор на 180 дней; аналитика и реклама не подключены. PHP-сессия нужна для CSRF и защиты от повторных обращений. Компании необходимо соблюдать фактические сроки, доступы и обязанности оператора; код не заменяет организационные меры.

Контакты и реквизиты перенесены из документа компании. Фото созданы ImageGen, карта — схема с переходом в Яндекс Карты. Перед клиентским запуском подтвердить фактические сроки изготовления/сварки, карту, фото и домен. Цвета в ПАЛИТРА.md используются всеми страницами.
