# Омега Комплект — демонстрация дизайна

Статическая адаптивная страница с самостоятельной композицией и увеличенными отступами. Палитра № 4 зафиксирована в ПАЛИТРА.md и dist/styles/tokens.css. Последняя редакция: 14 октября 2026 года.

Запуск: `npm run dev`, открыть http://127.0.0.1:4173. Установка зависимостей для сайта не нужна. dist/index.html также можно открыть непосредственно в браузере.

Файлы: dist/index.html — разделы и тексты; dist/styles/tokens.css — общая палитра и отступы; dist/styles/site.css — компоненты и адаптив; dist/scripts/site.js — меню и демонстрационное поведение; dist/assets — локальные шрифты, фото, схема карты и реквизиты.

Секции можно переставлять целиком внутри main. Изменение контактных данных выполняется в index.html и assets/rekvizity.txt. Названия марок станков находятся в элементах data-machine.

Форма не отправляет данные и не сохраняет их. Фотографии созданы ImageGen и не изображают реальное производство клиента. Карта — иллюстративная схема с переходом в Яндекс Карты для точного маршрута. Наименование ООО, ИНН, ОГРН, адрес, часы работы и условия доставки предоставлены заказчиком. Телефон и email сохранены из предыдущего макета. Сроки изготовления и сварки остаются демонстрационными. Предпросмотр закрыт от индексации.

До публичного запуска требуются финальная структура и продуктовые тексты, подтверждение телефона и email, настоящая карта или предоставленное клиентом изображение карты, подтвержденные сроки изготовления/сварки, фотографии предприятия, обработчик формы и согласованные юридические документы.

Проверка: `npm run verify` при запущенном сервере. Для инструмента проверки нужен Playwright в локальных node_modules или путь к нему в переменной CODEX_NODE_MODULES. Сам сайт работает без Playwright.
