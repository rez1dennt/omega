# Омега Комплект — демонстрация дизайна

Статическая адаптивная страница по последнему прикрепленному референсу (57f1691e-9418-4359-8890-77464c870634.png). Последняя правка заказчика отменяет самостоятельную светлую композицию: восстановлены темный первый экран, плавные линии и срезы, форма справа, компактные марки и доставка. Палитра № 4 зафиксирована в ПАЛИТРА.md и dist/styles/tokens.css.

Запуск: `npm run dev`, открыть http://127.0.0.1:4173. Установка зависимостей для сайта не нужна. dist/index.html также можно открыть непосредственно в браузере.

Файлы: dist/index.html — разделы, форма, контактные окна и реквизиты; dist/styles/tokens.css — палитра и масштаб макета; dist/styles/site.css — компоненты и адаптив; dist/scripts/site.js — меню, кастомный dropdown, вкладки марок, окна и демонстрационная форма; dist/assets — локальные шрифты, фото, схема карты и реквизиты.

Секции можно переставлять целиком внутри main. Изменение контактных данных выполняется в index.html и assets/rekvizity.txt. Названия марок станков находятся в элементах data-machine.

Форма не отправляет данные и не сохраняет их. Кнопки «Оставить заявку», «Подобрать полотно», «Подробнее» и «Связаться с нами» открывают модальное окно #request-dialog. Кнопка встроенной формы переносит размеры, TPI, материал, марку и комментарий в параметры заявки. Контакты и параметры сохраняются в памяти открытой страницы при закрытии окна. Перезагрузка очищает данные. Обязательные поля: параметры, email посетителя, российский телефон и согласие. Ошибки показаны под полями; результат явно указывает, что заявка не отправлена.

Нативное dialog-окно блокирует прокрутку страницы с компенсацией ширины полосы и фиксированной шапки. При закрытии восстанавливаются скролл и фокус. Escape, клик снаружи, крестик и циклический Tab/Shift+Tab поддерживаются. При переходе из информационного окна в заявку блокировка сохраняется. На маленьком экране прокручивается тело формы; шапка с крестиком остаётся доступной.

Выпадающий список TPI реализован своим DOM-компонентом: мышь, клавиатура, Escape, выбор и закрытие снаружи. Маска телефона работает при вводе и вставке, нормализует 8 в +7, позволяет Backspace/Delete пересекать скобки и дефисы. Фотографии созданы ImageGen. Карта — иллюстративная схема с переходом в Яндекс Карты. Контакты обновлены по DOC компании: основной телефон +7 (8452) 52-93-50, второй +7 (8452) 75-93-50, мобильный +7 (917) 206-21-00, omegakomplekt@mail.ru, офис 314. КПП и банковские реквизиты добавлены в скачиваемый файл.

Контакты, доставка, производство и Cookie-настройки используют общий dialogs.js: анимация открытия/закрытия и стабильный скролл. Вход элементов при прокрутке и микродвижение стрелок отключаются при prefers-reduced-motion. Доставка получила фото, маршрут, короткие условия и светлую карточку суммы. На мобильном карточка материалов не перекрывает сроки.

Политика — /privacy/, отдельное согласие — /consent/. Тексты и общий шаблон находятся в scripts/render-legal.mjs; после правок запустить npm run render:legal. Согласие относится к действующей демонстрации, не разрешает рекламу и будущую передачу заявок. Cookie-плашка хранит только omega-cookie-preferences в localStorage на 180 дней; аналитика и реклама отсутствуют. Настройки открываются из футера, запись можно удалить. Подробности и законодательные источники — docs/privacy-and-motion-2026-10-14.md. Документы описывают код сайта и не подтверждают соответствие всех процессов компании или инфраструктуры платформы требованиям РФ. Перед реальным приёмом данных нужны подтверждённая инфраструктура, сроки, получатели и организационные меры компании.

Проверка: `npm run verify`, `npm run verify:dropdown` и `npm run verify:modal` при запущенном сервере. Общий тест: девять ширин 1920, 1440, 1280, 1024, 926, 768, 390, 360, 320. Модалка: шесть ширин от 1440 до 320, реальная полоса Windows 15 px, сохранение геометрии и скролла, фокус, перенос данных, валидация, отсутствие отправки, reduced motion. Для проверок нужен Playwright в node_modules или путь к нему в CODEX_NODE_MODULES. Сам сайт работает без Playwright и установки зависимостей.
